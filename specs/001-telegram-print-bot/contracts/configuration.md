# Contract: конфигурация приложения

**Дата**: 2026-09-08 | Два источника: `.env` (секреты и пути) и `printers.toml` (список принтеров).
Оба читаются при старте и валидируются; при ошибке приложение не стартует и пишет причину в лог и в консоль.

## `printers.toml`

```toml
[[printer]]
key = "buh"                      # идентификатор для callback_data, [a-z0-9_]{1,16}, уникален
display_name = "Бухгалтерия"     # что видит пользователь в списке
system_name = "Pantum P5100"     # точное имя принтера в Windows
model = "Pantum 5100"            # справочно
enabled = true                   # можно выключить, не удаляя
# supports_duplex = true         # необязательно: переопределяет автоопределение
# supports_a3 = true             # необязательно: разрешить выбор бумаги A3

[[printer]]
key = "office"
display_name = "Кабинет"
system_name = "GM1033ADN"
model = "GM1033ADN"
enabled = true
```

**Правила валидации при старте (FR-012…FR-015)**
1. Хотя бы один принтер с `enabled = true`; иначе — старт с ошибкой.
2. `key` уникальны; `system_name` уникальны.
3. Для каждого `system_name` проверяется наличие в системе; отсутствующий принтер логируется как предупреждение и показывается пользователю недоступным, старт не блокирует.
4. `supports_duplex` и `supports_a3` определяются автоматически через `DeviceCapabilities`; значения из файла имеют приоритет.
5. Добавление принтера = добавление блока `[[printer]]` + перезапуск бота; пользовательский сценарий при этом не меняется (SC-008).

## Что не настраивается в первой версии

Ориентация (книжная), цветность (ч/б), диапазон страниц, выбор лотка — зафиксированы допущениями спеки и вынесены в код как константы `PrintOptions` по умолчанию. Формат бумаги настраивается пользователем (A4 или A3) там, где принтер поддерживает A3.
